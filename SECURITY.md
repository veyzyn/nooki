# Security policy

## Supported versions

Nooki is in early development. Security fixes are made only on the latest published version.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or accidentally exposed secret. Use GitHub's private vulnerability reporting feature for this repository.

Include the affected version, reproduction steps, expected impact, and any suggested mitigation. Please allow time for the report to be confirmed and fixed before discussing it publicly.

Minecraft worlds, server archives, credentials, and private keys should never be attached to an issue or report unless they have been replaced with safe test data.
