# Changelog

## [0.1.2] - 2026-08-13

### Added

- A built-in server file browser with breadcrumbs and an integrated editor for text and configuration files.
- Version selection before installing mods and plugins, plus multi-file local imports that copy the original files.
- A two-line Minecraft MOTD editor with formatting and alignment controls.
- Real Minecraft player avatars in player lists.
- A native startup screen while Nooki prepares the local database and server state.

### Improved

- Modrinth and CurseForge browsing, metadata, icon handling, and compatible-version discovery.
- Server navigation, icons, menus, alerts, form controls, empty states, and subtle interface motion.
- Console responsiveness when servers produce a large amount of output.

### Fixed

- Servers that are force-closed after a requested stop are no longer incorrectly reported as crashes.
- Modpack artwork from supported catalog image formats can be used as the server icon reliably.
- Crashed servers now leave the starting state and expose the correct recovery actions.
